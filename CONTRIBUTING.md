# Contributing to RoastHub 🔥

Thank you for wanting to make RoastHub even more savage! We welcome contributions from developers, designers, humorists, and battle-hardened architects.

---

## 🎭 How You Can Contribute

1. **Add Roasts to the Procedural Matrix**:
   - The comedy matrix lives in `src/lib/roastEngine.ts`.
   - Submit PRs adding new witty one-liners, tech punchlines, VC parody quotes, or repo autopsy causes of death.
2. **Expand Tech Tags & Cost Metrics**:
   - Add new emerging frameworks, cloud services, and tools to Mode C (`Stack Roast`).
3. **Enhance Visual Artifacts**:
   - Improve receipt styling, custom stamps, thermal paper textures, and canvas rendering.
4. **Fix Bugs or Add Tests**:
   - Strengthen the Vitest suite in `tests/`.

---

## 📜 Contribution Rules & Code of Conduct

1. **Strict Safety Policy**:
   - As declared in `AGENTS.md`, roasts must strictly target code quality, technical architecture, VC jargon, and engineering absurdities.
   - **Zero tolerance** for hate speech, sexism, racism, or attacks targeting personal individuals or identity groups.
2. **Keep It Funny & High-Signal**:
   - Good roasts are grounded in real developer pain (e.g. debugging Webpack configs at 3 AM, overpaying for unused RDS clusters, or naming commits `"asdf"`).
3. **Zero External Backend**:
   - RoastHub is 100% client-side and hosted on GitHub Pages. Do not introduce server-side database requirements.

---

## 🛠️ Local Development Setup

```bash
# 1. Clone repository
git clone https://github.com/1997agarwal/RoastHub.git
cd RoastHub

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Run test suite
npm test

# 5. Typecheck
npm run typecheck
```

---

## 🚀 Submitting a Pull Request

1. Fork the repository and create your feature branch: `git checkout -b feature/savage-rust-roast`.
2. Commit your changes: `git commit -m 'feat: add savage roasts for Rust rewrite addicts'`.
3. Verify tests and types: `npm test && npm run typecheck`.
4. Push to branch and open a PR against `main`.
