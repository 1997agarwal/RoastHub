## 🌟 What is RoastHub?

**RoastHub** is an unapologetic, hilarious, and 100% client-side web application where founders, developers, and architects get their startup pitches, GitHub repositories, and tech stacks roasted to ashes in under 3 seconds.

Built for instant viral sharing: every roast produces an aesthetic, high-res downloadable **"Thermal Roast Receipt"** or **"VC Rejection Memo"** stamped in red, with 1-click sharing to **X (Twitter)**, **LinkedIn**, and **Reddit**.

## ⚡ The Three Roast Engines

### 1. 🔥 Mode A: Pitch Roast (Founders & Indie Hackers)
- **Input**: Startup tagline or elevator pitch + target audience.
- **Selectable VC Personas**:
  - 🧢 **The Hype-Beast Crypto/Agentic VC**: Obsessed with tokens, autonomous loops, and imaginary TAMs.
  - 👔 **The Savage YC Partner**: Grills user retention, unscalable manual work, and zero revenue.
  - 🍜 **The Bootstrapped Ramen Dev**: Roasts spending money on wrappers, vanity metrics, and fancy landing pages.
  - 💼 **The Corporate Boomer**: Demands SOC2 compliance and SAP enterprise integration for a simple todo list.
- **Metrics**:
  - **Buzzword Fluff Meter (0–100%)**: Weighted keyword detector for *disrupt, revolutionize, seamless, flywheel, synergy, AI-native*.
  - **3 Brutal Truths**: Why your TAM is a hallucination and churn will be 99%.
  - **The "Honest Parody" Re-write**: Translates corporate speak into reality (e.g., *"Uber for dogs" $\to$ "You walk strangers' labradors for \$8/hr"*).
  - **Official VC Rejection Memo**: Thermal receipt stamped with `[HARD PASS: CALL US WHEN YOU HAVE HUMAN USERS]`.

### 2. 💀 Mode B: Repo Roast (Developers & Maintainers)
- **Input**: Public GitHub repository URL or `owner/repo` (e.g., `facebook/react`, `torvalds/linux`, or custom repos).
- **GitHub REST API Forensics**:
  - **Commit Message Forensics**: Scans for lazy commits (`"wip"`, `"fix"`, `"pls work"`, `"asdf"`, `"final v2"`).
  - **Zombie Issues & PR Ratio**: Flags open issues abandoned for years.
  - **Test Coverage Detection**: Inspects test directories and CI workflows.
  - **Dependency Bloat**: Flags overkill libraries and package sprawl.
- **Outputs**:
  - **Repo Autopsy Certificate**: Cause of death (e.g., *"Fatal Overdose of `console.log` in Production"*).
  - **Bus Factor Score**: Rating from *"One guy named Dave who doesn't answer Slack"* to *"Immortal"*.
  - **Shareable Technical Debt Receipt**.

### 3. 🏗️ Mode C: Stack Roast (Architects & Tech Leads)
- **Input**:
  - Multi-select interactive tech tags: *Next.js, Tailwind, Rust, Go, Kubernetes, Kafka, Redis, MongoDB, Microservices, GraphQL, Docker, AWS Lambda, Terraform, Cassandra*.
  - App Type Selector: *Personal Blog, Todo List, MVP SaaS, E-Commerce Store, Internal Admin Dashboard*.
- **Outputs**:
  - **Over-Engineering Severity Score**: 0 (Clean & Sane) to 100% (Certified Resume-Driven Development).
  - **Estimated Monthly Cloud Waste**: Calculates how much AWS/GCP bill is wasted serving 12 visitors.
  - **Senior Architect Diagnosis**: Savage one-liners on why you built a lunar lander to fetch coffee.
  - **Downloadable "Architectural Sins Card"**.

## 🎨 Aesthetic & Interactive Details

- **Color Palette**: Deep Charcoal/Jet Black (`#0a0a0c`), Neon Flame Orange (`#ff5500`), Electric Amber (`#ffaa00`), and Bone White text (`#f8fafc`).
- **Typography**: Retro monospaced terminal fonts (`JetBrains Mono`, `Courier Prime`) paired with modern sans-serif headings.
- **Audio & Haptics**: Procedural Web Audio API sound synthesizer:
  - 💥 Flame whoosh on roast generation
  - ⌨️ Typewriter clatter during text streaming
  - 🧾 Paper rip & cash-register chime on card generation
  - 🔨 Rubber stamp thud on verdict stamp
- **Interactive FX**: Floating ambient ember particles, retro CRT scanline effects, jagged receipt paper edges, and barcode generation.

## 🚀 Quickstart & Local Development

RoastHub requires **Node.js 18+** and runs with zero external backend or database setup.

```bash
# 1. Clone the repository
git clone https://github.com/1997agarwal/RoastHub.git
cd RoastHub

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Open in browser
# http://localhost:5174/
```

### Running Automated Tests

```bash
# Run Vitest test suite
npm test

# Run TypeScript typecheck
npm run typecheck
```

### Production Build

```bash
# Compile to optimized static bundle in dist/
npm run build
```
